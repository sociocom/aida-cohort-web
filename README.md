# AIDA Cohort Web

AIDA Cohort（AIDA／あいだコホート）の対外広報・公式研究紹介サイトです。

`Human × AI × Well-being` をブランドと情報設計の中心に置き、人とAIとの関わり方と、人の幸福・健康・生活との関係を長期的に観察する研究であることを伝えます。テーマカラーは `#1CB299` です。

本バージョンは1ページ構成です。「調査に参加される方へ」の独立ページや導線は設けません。

## ファイル構成

- `index.html`：公式研究紹介サイト本体
- `styles.css`：デザイントークン、レイアウト、コンポーネント、レスポンシブ／アクセシビリティ対応
- `DESIGN_SPEC.md`：現行の設計・コンテンツ仕様（v0.2）

HTMLとCSSのみで動作し、JavaScript、npm、ビルドツール、UIフレームワークは不要です。

## サイトの内容

公開ページは、次の情報を一続きで案内します。

- `Human × AI × Well-being` とAIDA Cohortの問題意識
- AIDAコホートの概要と「コホート」の説明
- 研究上の問いと、今この研究を行う理由
- 約1,000名予定、3か月ごと、最低4年間・継続予定という調査設計
- 初回・定期・自由記述の調査項目
- 長期データの蓄積、分析、研究成果としての還元という目指す流れ
- 現時点で確認できる学際的な研究領域
- 奈良先端科学技術大学院大学 先端科学技術研究科 ソーシャル・コンピューティング研究室
- 研究支援に関する謝辞

研究代表や各研究メンバーの個別情報、追加の研究・連携機関、NEWS、研究成果、問い合わせは、正式情報の受領後に掲載できる構造とします。未確認の氏名・所属・記事・連絡先などは公開ページにダミー表示しません。

## ローカル確認

リポジトリのルートで任意の静的ファイルサーバーを起動します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## GitHub Pages

ルートの静的ファイルをそのまま配信できます。GitHubリポジトリの Pages 設定で、公開元を対象ブランチのルートに設定してください。

公開前には、デスクトップとスマートフォンで表示を確認し、リンク、見出し階層、キーボード操作、フォーカス表示、文字サイズ、コントラスト、横方向のオーバーフローを点検してください。

## 追加掲載に必要な正式情報

次の情報は、提供・確認されるまで掲載しません。

### 研究代表

- 氏名、所属、職位、専門
- 掲載許諾済みの写真
- 短いプロフィール
- AIDA Cohortについてのメッセージ

### 研究チーム・研究機関

- 各メンバーの氏名、所属、役割、専門領域
- 研究実施機関、共同研究機関、研究協力機関の正式名称
- 使用許諾済みの正式ロゴデータ

### コホートの詳細プロフィール

- 調査開始時期
- 調査対象者、対象年齢、募集方法
- AI利用者／非利用者の扱い

### NEWS / Updates

- 実際の公開日
- 正式な見出しと本文またはリンク先
- 公開責任者による掲載承認

### Publications / Outputs

- 論文、学会発表、プレスリリース、メディア掲載、研究報告の確定情報
- 著者、題名、掲載先、発表年、識別子または正式URL

### Contact

- 正式な問い合わせ窓口名
- 公開可能なメールアドレス等
- 必要に応じて対応範囲や受付方針

### Funding / Acknowledgements

- 既存資料にある研究費・事業名が最新の正式名称であることの確認
- 掲載すべき支援機関名・表記順・ロゴの有無

未確認情報は、架空の内容、`TBD`、ダミー記事、仮メールアドレスとして公開画面へ出さず、HTMLコメントまたは管理上のTODOに留めます。
